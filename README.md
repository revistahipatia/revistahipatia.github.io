# revistahipatia.github.io
Revista de Matemática Hipátia

Para publicar uma nova edição (converter os artigos em LaTeX para HTML
via pandoc e integrá-los ao site), siga o passo a passo em
[`docs/nova-edicao.md`](docs/nova-edicao.md). Os scripts de apoio usados
nesse processo estão em [`scripts/`](scripts/).

Veja também [`CLAUDE.md`](CLAUDE.md) para as convenções gerais do site
(SEO, identidade visual, e a restrição de que o site fica embutido em um
iframe no site oficial da UFBA).
